# Vision

## Product Vision

StellaAtlas는 누구나 복잡한 날씨와 천문 지식 없이도 밤하늘을 즐길 수 있도록
돕는 개인 관측 안내 서비스입니다.

서비스가 답해야 하는 핵심 질문은 다음과 같습니다.

> Is tonight a good night to observe the stars?

## Problem

기존 날씨 서비스는 기온, 강수량, 구름량 같은 데이터를 제공하지만 해당 수치가
별 관측에 어떤 의미인지 설명하지 않습니다. 천문 정보 역시 여러 서비스에
분산되어 초보자가 관측 여부와 시간을 스스로 판단하기 어렵습니다.

## Principles

1. **빠른 판단**: 사용자는 몇 초 안에 오늘 관측 여부를 결정할 수 있어야 합니다.
2. **쉬운 설명**: 전문 수치보다 사용자가 취할 행동과 그 이유를 먼저 전달합니다.
3. **설명 가능한 결과**: 점수와 추천에 영향을 준 조건을 숨기지 않습니다.
4. **위치 정보 보호**: 정확한 위치는 필요한 범위에서만 처리하고 저장을
   최소화합니다.
5. **점진적 확장**: 관측 조건 안내의 신뢰성을 먼저 확보한 후 로컬 관측 기록,
   밤하늘 탐색과 개인화를 확장합니다.

## Initial Success

초기 제품은 사용자가 위치와 날짜를 선택하면 시간대별 관측 조건, 가장 좋은
관측 시간과 이해하기 쉬운 이유를 안정적으로 제공할 때 성공한 것으로 봅니다.

## Non-Goals

초기 제품은 다음을 목표로 하지 않습니다.

- 망원경 실시간 제어
- 천체사진 자동 분석
- 소셜 네트워크 또는 실시간 채팅
- 복잡한 구독과 거래 기능
- 검증되지 않은 마이크로서비스 분리
